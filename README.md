# ip-hosting-site

Сайт-визитка ИП по организации проживания командированных сотрудников и монтажных бригад.

## Что уже сделано

- адаптивная одностраничная версия;
- услуги по размещению командированных;
- блок аренды спецтехники;
- блок отдельных монтажных работ;
- география и схема работы;
- форма для подготовки текста заявки;
- собственные SVG-иллюстрации без внешних лицензий и зависимостей.

## Что нужно заполнить перед публикацией

В `index.html` заменить:

- `+7 (___) ___-__-__` на рабочий телефон;
- `укажите рабочую почту` на e-mail;
- `ИП — реквизиты добавить` на ФИО/наименование ИП и при необходимости ИНН/ОГРНИП;
- при желании название «Командировка Сервис» на фактическое коммерческое название.

## Запуск

Сайт статический. Для локального просмотра достаточно открыть `index.html` в браузере.

Для публикации можно использовать GitHub Pages или любой обычный веб-хостинг.
